# Website Content Documents

Drop any Word documents (`.docx`, `.doc`), notes, or text files in this folder (or in the subfolders below). I will read and integrate the content directly into the corresponding sections of your website.

### Suggested Folder Organization:
- `home/` — Copy, headlines, bio, service details, client list updates for `index.html`
- `about/` — Background story, awards, experience, philosophy for `about.html`
- `services/` — Detailed descriptions, deliverables, and pricing for services
- `projects/` — Case study copy, client descriptions, project goals for portfolio items
- `contact/` — Inquiries, contact details, social links, FAQs

You can also drop files directly into this `content_docs/` folder root and let me know which page or section they belong to!
